# Crop Recommendation ML

A machine learning project that predicts the most suitable crop based on soil nutrients, weather conditions, and pH values.

## Project Overview

This project uses classification algorithms and agricultural data analysis techniques to recommend the best crops for farming conditions. The goal is to support smarter and more data-driven agricultural decisions.

## Features

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Crop classification and prediction
* Model training and evaluation
* Agricultural data visualization

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Jupyter Notebook

## Dataset Attributes

* Nitrogen (N)
* Phosphorus (P)
* Potassium (K)
* Temperature
* Humidity
* pH
* Rainfall

## Objective

To build a predictive machine learning model capable of recommending the most suitable crop for specific environmental and soil conditions.

## Author

Developed as a machine learning and data science project for agricultural analytics.
